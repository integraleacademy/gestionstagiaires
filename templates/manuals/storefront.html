{% call faq_panel("questions", "faq-title", "FAQ INTÉGRALE CONNECT", "Vos questions. Nos réponses.", "Les informations utiles pour préparer votre prochaine commande.", "orange") %} {% call faq_item(1, "Quelle est la quantité minimale de manuels ?") %}

Vous pouvez commander à partir de 50 exemplaires par titre. Un tarif dégressif s’applique dès 100 exemplaires d’un même manuel. Les quantités de titres différents ne se cumulent pas pour ce palier.

Consulter les manuels et tarifs → {% endcall %} {% call faq_item(2, "Mon logo est-il inclus dans le prix ?") %}

Oui, la personnalisation de la couverture avec votre logo et la livraison sont incluses. Vous pouvez transmettre votre logo à la commande ou depuis son suivi. Vous vérifiez puis validez le bon à tirer avant l’impression.

Voir les étapes de personnalisation → {% endcall %} {% call faq_item(3, "Quel délai prévoir pour recevoir mes supports ?") %}

Comptez environ 10 à 15 jours pour les manuels, après règlement et validation du bon à tirer, et 1 semaine pour les clés USB après paiement. Les accès e-learning peuvent être envoyés par votre centre dès confirmation du paiement. Pour une date impérative, contactez-nous avant de commander.

Appelez-nous au 04 22 47 07 68 → {% endcall %} {% call faq_item(4, "Que contient la clé USB ?") %}

Elle contient le support PowerPoint de la formation choisie. L’achat est unique, à 99 € ou 199 € TTC selon la référence, avec la clé et la livraison incluses. Les manuels sont vendus séparément. Prévoyez PowerPoint ou un lecteur compatible.

Découvrir les supports et leurs extraits → {% endcall %} {% call faq_item(5, "Comment fonctionnent les accès e-learning ?") %}

Depuis votre espace organisme, commandez des accès individuels ou créez un groupe. Après confirmation du paiement, cliquez sur « Envoyer les accès e-learning aux stagiaires » : chacun reçoit alors son lien personnel. Votre centre retrouve la progression, le temps suivi et les relevés de connexion.

Voir les parcours disponibles → {% endcall %} {% call faq_item(6, "Puis-je découvrir les supports avant de commander ?") %}

Oui. Vous pouvez feuilleter les extraits des manuels, consulter les aperçus PowerPoint et explorer les démonstrations e-learning. La démonstration APS présente aussi le suivi côté organisme avec des données fictives.
