Configurer la connexion
  1. Ouvrez le service gestionstagiaires-test-v2 dans Render, puis Environment → Edit.
  2. Ajoutez EDOF_EFP_USERNAME : l’e-mail de votre compte EFP habilité pour cet établissement.
  3. Ajoutez EDOF_EFP_PASSWORD : le mot de passe de ce compte.
  4. Enregistrez avec Save, rebuild, and deploy, attendez que le service soit disponible, puis rechargez cette page.

Saisissez ces valeurs uniquement dans Render. Aucun mot de passe n’est demandé sur cette page ni dans le chat.

Un formulaire accessible ne prouve pas une connexion réussie. Une lecture réussie ne prouve pas encore le fonctionnement continu après expiration, ni les déclarations d’entrée et de sortie.

Chaque essai dure au maximum 2 min 30 et fonctionne sur Render, même si vous fermez cette page. Les sessions EFP du test sont temporaires. Les résultats sont conservés au maximum 24 heures et purgés à l’accès suivant. En cas de code de vérification, de CAPTCHA ou de parcours inconnu, l’essai s’arrête.
