{% if not gmail.configured %}
Configuration Google à terminer une seule fois
  1. Dans un projet Google Cloud de votre organisme, activez Gmail API et configurez l’écran d’autorisation Google.
  2. Créez un client OAuth de type Application Web, avec cette URL de redirection :
    https://gestionstagiaires-test-v2.onrender.com/admin/edof-test/server/gmail/callback
  3. Dans Render → gestionstagiaires-test-v2 → Environment, ajoutez EDOF_GOOGLE_CLIENT_ID et EDOF_GOOGLE_CLIENT_SECRET avec les deux valeurs fournies par Google. Enregistrez et redéployez.
  4. Revenez ici et utilisez le bouton de connexion Google. Si l’application Google est en mode test, ajoutez d’abord votre adresse Gmail aux utilisateurs de test.

Pour un compte Gmail externe, le mode test Google limite normalement cette autorisation à sept jours. Le fonctionnement durable nécessite une configuration Google adaptée et les validations éventuellement requises.

{% endif %} {% if not gmail.protected %}
