01

Installer le module Chrome

Une seule installation sur votre ordinateur.

Télécharger le module
Comment l’installer
  1. Décompressez le fichier téléchargé.
  2. Ouvrez chrome://extensions dans Chrome.
  3. Activez « Mode développeur », puis « Charger l’extension non empaquetée ».
  4. Sélectionnez le dossier integrale-edof-test, qui contient manifest.json.
  5. Fermez puis rouvrez les outils de développement de votre onglet EDOF.
02

Préparer un dossier

Saisissez le numéro CPF du dossier que vous souhaitez lire.

03

Transmettre depuis EDOF

  1. Connectez-vous normalement à EDOF et ouvrez le dossier choisi.
  2. Ouvrez les outils de développement : ⌥ ⌘ I sur Mac.
  3. Choisissez l’onglet Intégrale EDOF (éventuellement dans le menu »).
  4. Collez le code, cliquez sur Préparer la lecture, puis rechargez le dossier EDOF.
  5. Vérifiez le dossier détecté et cliquez sur Transmettre à Gestion Stagiaires.
